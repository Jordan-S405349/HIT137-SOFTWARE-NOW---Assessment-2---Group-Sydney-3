# About this task

This task has two parts:

Question 1: Cipher Program (cipher.py) A program that encrypts and decrypts text files using custom case-sensitive substitution rules, then verifies that the decrypted output matches the original.

Question 2: Expression Evaluator (evaluator.py) A program that reads mathematical expressions from a file, tokenizes them, builds a parse tree using recursive descendant parsing, evaluates the result, and writes the output to a file.
